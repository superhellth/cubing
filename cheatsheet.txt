Postgres:
switch to postgres user: sudo -i -u postgres
postgres command-line: psql

NGINX Webserver config:
certbot --nginx -d yourdomain.com
nano /etc/nginx/sites-available/highpercube
ln -s /etc/nginx/sites-available/your_site_name /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx

UFW Firewall config:
ufw allow from <IP> to any port <PORT>
ufw status numbered + ufw delete <number>

PM2 for backend:
pm2 start ./dist/app.js --name "highpercube"
pm2 save
pm2 startup

pm2 list
pm2 delete <name>
pm2 save
